# Naming policy

The licenses in this repository cover the code, not the name.

**TuxMix** is the name of this project. Forks are welcome — the licenses
allow them — but a fork runs under its own name, and it does not suggest
that it is the TuxMix project or that it is endorsed by it.

If you publish one:

- pick a different name and a different icon;
- keep the copyright and license notices the licenses require, and say
  plainly in the README that it is a fork and what it changes;
- linking back here is a courtesy, and it is how users find the upstream
  when they hit a bug you inherited.

If your project adds something this one does not do, a link from the
README's Related line is welcome — open an issue and it will be added.

RME, Fireface, Babyface and TotalMix are RME's trademarks. TuxMix works
with those interfaces; it is not affiliated with RME and is not endorsed
by them.
